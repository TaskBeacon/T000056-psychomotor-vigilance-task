# Task Plot Brief

- Title: Psychomotor Vigilance Task
- Construct: sustained attention / behavioral alertness
- Visual format: two-row timeline collection on white background with a blank header band.
- Standard event row: blank black screen for a random 2-10 s interval, centered red five-digit millisecond counter for up to 65 s, then red RT feedback for 500 ms after a valid Space response.
- Recorded exceptions row: premature Space during the blank interval or target RT below 100 ms is a false start; target RT above 500 ms is a lapse and still receives RT feedback; no response for 65 s ends the event without feedback.
- Visible target: red `00000`-style counter centered on a black participant screen.
- Response key: `SPACE`.
- Do not show participants, devices, condition tokens, rewards, accuracy feedback, or a fixation cross.
