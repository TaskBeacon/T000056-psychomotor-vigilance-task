## 1. Task Overview

This task implements a visual Psychomotor Vigilance Task (PVT). Participants wait through an unpredictable blank interval and press Space as soon as a red millisecond counter appears. The task measures response speed, lapses, false starts, no-response events, and time-on-task degradation without a choice or learning component.

The human profile contains one uninterrupted 90-event block, approximating the standard 10-minute PVT session described in the selected literature. QA and simulation profiles shorten event counts and runtime while retaining the same phase and outcome semantics.

## 2. Task Flow

![Task Flow](task_flow.png)

### Block-Level Flow

The block-level flow is instruction, one continuous vigilance block, completion summary, and exit.

### Trial-Level Flow

Each event follows this participant-visible sequence:

1. A blank black response-stimulus interval lasts randomly from 2 to 10 seconds. Pressing Space here is recorded as a false start.
2. A centered red five-digit millisecond counter appears and advances until response.
3. Pressing Space records RT. Responses below 100 ms are false starts; responses above 500 ms are lapses.
4. Valid responses display the measured RT for 500 ms. Failure to respond within 65 seconds is recorded as no-response.
5. The next event begins with a newly sampled blank interval.

### Controller Logic

There is no adaptive controller. Conditions are generated by the standard `BlockUnit.generate_conditions()` path using the single `standard` label.

## 4. Methods (for academic publication)

Participants completed a computerized visual Psychomotor Vigilance Task implemented with PsychoPy and PsyFlow. Each event began with a blank response-stimulus interval sampled uniformly from 2 to 10 seconds. A red five-digit millisecond counter then appeared at screen center, and participants responded as quickly as possible by pressing the space bar. Reaction time was measured from target onset. Pre-target responses and target responses faster than 100 ms were classified as false starts, responses slower than 500 ms as lapses, and failures to respond within 65 seconds as no-response events. After each valid response, the recorded reaction time was displayed for 500 ms. The baseline profile comprised one uninterrupted block of 90 events.

Primary outcomes include mean and median valid RT, reciprocal response speed, lapse count, false-start count, no-response count, and response-speed change over event order. Protocol choices and evidence mappings are documented under `references/`.
